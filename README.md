

 Click To Go – Bookmark Landing Page

**Click To Go** is a simple and visually appealing bookmark landing page created using **HTML5 and CSS3**.
It allows users to quickly open their favorite websites from a single stylish dashboard.

---

✨ Features

* Modern gradient background design
* Glass-style sticky navigation bar
* Smooth hover animations and transitions
* Bookmark cards with icons/images
* Responsive Flexbox layout
* External links open in a new tab
* Beginner-friendly code structure
* No JavaScript required

---

## 🛠 Technologies Used

* **HTML5**
* **CSS3**

  * Flexbox
  * Gradients
  * Shadows
  * Hover Effects
  * Backdrop Blur

---

 📌 Purpose of the Project

This project was built as:

* A **personal browser start page**
* A **front-end practice project**
* A **portfolio demo for beginners**
* A way to learn **layout design and UI styling**

 🚀 How to Use

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. Click on any bookmark card to open the website.
